FAQ

Questions people actually ask, answered without a hotline.

Is it free?

Yes. No account, no watermark you can't turn off, no catch. The helper is free and open source too.

What gets installed, and why does Windows warn me?

Only for keys and mouse: input-overlay, a small free OBS add-on made by univrsal, downloaded straight from its GitHub. It's open source but not paid-for "signed", so Windows SmartScreen may say it doesn't recognise it. Click More info, then Run anyway. Controllers need nothing installed.

Will chat see what I type, like passwords?

No. Only the keys in your layout light up, one at a time, and it never shows text. Typing your password shows a few keys flashing, not the letters in order.

Does it work on a Mac?

Controllers do, nothing to install. The keyboard and mouse helper is for Windows (and Linux), so on a Mac pick Controller.

Streamlabs, Meld or another app?

Keys and mouse need OBS, because the helper is an OBS add-on. The controller version is just a Browser source, so it works in anything that can show a web page.

Will anti-cheat mind?

It only listens to key presses, the same way OBS hotkeys do, and never touches your game.

Can I change it later?

Any time. Come back, pick a new look, copy the new link and paste it over the old one in the Browser source.

Nothing lights up. Now what?

Check page 5: the box ticked in input-overlay settings, and OBS restarted since. For controllers, press any button once after OBS opens so it wakes up.
